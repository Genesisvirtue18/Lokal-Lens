Lokal Lens: test guide

Isse kaise use karein (30 second)
  1. Neeche ke steps upar se neeche, order mein karo. Har step mein likha hai kya karna hai aur kya dikhna chahiye.
  2. Jo dikhna chahiye wahi dikha to Pass dabao. Alag dikha ya error aaya to Fail dabao aur saamne ek line likh do ki kya dikha.
  3. Ye page aapka progress khud yaad rakhta hai (is computer ke browser mein). Band karke dobara khol sakte ho.
  4. Sab ho jaye to upar "Fail ki list copy karo" dabao aur wo text mujhe chat mein paste kar do. Main sab theek kar dunga.

Teen role teen alag browser mein: Admin Chrome, Owner Edge (ya Chrome ka doosra profile), Customer Incognito window. Ek hi browser mein do role mat rakhna.

Tayyari (pehle ye karo)

Terminal mein ye commands chalani hain. Har box ke "Copy" se copy karke paste karo.

1. Backend chalao (terminal 1) 
cd Directory_backend-main\Directory_backend-main
npm run dev
2. Frontend chalao (terminal 2, main project folder mein) 
npm run dev
3. Mail chalti hai ya nahi (terminal 3, backend folder mein) apna email daalo: 
cd Directory_backend-main\Directory_backend-main
node scripts/send-test-email.js aapki@gmail.com
4. Apna admin banao (terminal 3, ek hi line mein, naam/email/password apne daalo): 
$env:ADMIN_EMAIL="aapki@gmail.com"; $env:ADMIN_NAME="Aapka Naam"; $env:ADMIN_PASSWORD="koi-lamba-password-123"; node scripts/create-admin.js
5. (Sirf "shuru se khali platform" dekhna ho to) backend ki .env mein MONGODB_URI ka naam business_directory se lokal_lens_fresh kar do aur backend restart karo. Purana data bacha rehta hai.

Teen email: Gmail ka + trick: aapki@gmail.com (admin), aapki+owner@gmail.com (owner), aapki+customer@gmail.com (customer). Teeno ki mail ek hi inbox mein aati hai.

Local par poori kahaani (chapter 1 se 11). Live par sirf chapter 12 ka chhota check. Computer se automatic tests (admin, owner, forms, phone screen, security) pehle hi pass hain, ye guide sirf aankh se dekhne aur Google/Gmail wali cheezon ke liye hai.
