1. Ye document kya hai aur kaise use karein

  1. Is document mein 70 test cases hain (TC-01 se TC-70). Inhe order mein karna hai. Order maine is tarah rakha hai ki pehle wale case ka data agle ke kaam aaye.
  2. Har test case mein 4 cheezein hain: kaun karega (aur kaunse browser mein), pehle se kya chahiye, steps (ek ke baad ek) aur expected result (kya dikhna chahiye).
  3. Steps karo. Jo dikhna chahiye wahi dikha to Pass chuno. Kuch alag dikha ya error aaya to Fail chuno aur remarks mein ek line likho ki kya dikha.
  4. Ye page aapka kaam apne aap yaad rakhta hai (is computer ke browser mein). Band karke dobara khol sakte ho.
  5. Sab ho jaye to upar "Fail ki list copy karo" dabao aur wo text chat mein bhej do. Jo fail hue wo main theek karunga.
  6. Chhapna ho to upar "PDF / Print" dabao.
Teen alag browser kyun? Admin, Owner aur Customer ek saath alag login rehte hain. Ek hi browser mein do role mat rakho, nahi to purana login gadbad karta hai.
  • Browser A = Chrome: Admin
  • Browser B = Edge (ya Chrome ka doosra profile): Owner
  • Browser C = Incognito window: Customer aur bina login wale kaam

5. Test cases

A. Admin: platform ki shuruaat

Platform abhi khali hai. Pehle admin apna account aur categories taiyar karta hai.

TC-01

Admin login aur authenticator lagana

Admin High
Kaunsa browser: Browser A (Chrome)    Pehle se chahiye: Setup ka step S4 (admin banana) ho chuka ho.

Kya karna hai (steps)

  1. Browser A mein http://localhost:3000/login kholo.
  2. "Use password instead" dabao.
  3. Admin ka email aur password daalo, "Sign in" dabao.
  4. Phone mein Google Authenticator kholo, "+" dabake screen ka QR code scan karo.
  5. Authenticator mein jo 6 akshar ka code dikhe, wo box mein daalo, "Verify" dabao.
  6. 8 backup codes dikhenge. Inhe copy ya download karke kahin safe save karo, phir "I saved these" dabao.

Kya dikhna chahiye (expected result)

  • Login ke baad QR code dikhta hai.
  • Galat code par error aata hai, sahi par aage badhta hai.
  • 8 backup codes dikhte hain.
  • Aakhir mein /admin ka dashboard khulta hai.
